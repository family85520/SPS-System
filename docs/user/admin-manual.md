# 管理员操作手册

**文档版本：** V1.0
**最后更新：** 2026-07-10
**适用对象：** 超级管理员、排班管理员

---

## 1. 系统登录

1. 打开浏览器访问系统地址
2. 输入用户名和密码
3. 首次登录系统会强制要求修改密码

**默认账号：**
- 用户名：`admin`
- 密码：`admin123`（首次登录强制修改）

---

## 2. 组织架构管理

### 2.1 创建组织

1. 进入「组织架构」页面
2. 点击「新建组织」
3. 填写组织名称、选择上级组织
4. 部门代码可自动生成或手动输入
5. 点击保存

**规则：**
- 最多支持 4 级组织层级
- 同级组织名称不可重复
- 部门代码全局唯一

### 2.2 停用/删除组织

- **停用：** 点击组织行操作列的停用按钮
- **删除：** 仅当组织下无人员、无子组织、无排班记录时可删除

---

## 3. 人员管理

### 3.1 创建人员

1. 进入「人员管理」页面
2. 点击「新增人员」
3. 填写姓名、选择所属组织
4. 工号可自动生成或手动输入
5. 选择人员标签（如"带班领导"、"新入职"）
6. 勾选"创建登录账号"（用户名=工号，初始密码 123456）
7. 点击保存

### 3.2 批量操作

| 操作 | 路径 | 说明 |
|------|------|------|
| 批量重置密码 | 工具栏 → 批量重置密码 | 将选中人员密码重置为 123456 |
| 批量创建账号 | 工具栏 → 批量创建账号 | 为无账号的历史人员创建账号 |

### 3.3 管理账号

右键点击人员 → 管理账号：
- 启用/禁用账号
- 重置密码
- 重新分配角色

---

## 4. 班次模板管理

### 4.1 创建班次

1. 进入「班次模板」页面
2. 点击「新建班次」
3. 填写班次名称、时间范围
4. 选择颜色标识
5. 设置值班领导人数（最少/最多）
6. 设置值班人员人数（最少/最多）
7. 选择适用日期（周一~周日）
8. 点击保存

### 4.2 值班组管理

在班次模板详情页可管理值班组：
- 创建/编辑/删除值班组
- 设置组内人员和优先级
- 启用/停用值班组

---

## 5. 约束规则管理

### 5.1 预置规则

系统预置了 8 条约束规则，不可删除：

| 规则名称 | 默认值 | 说明 |
|---------|--------|------|
| 连续工作上限 | 5 天 | 每人最多连续工作天数 |
| 连续工作后最少休息 | 1 天 | 连续工作后必须休息天数 |
| 班次最少间隔 | 8 小时 | 相邻班次最小间隔 |
| 夜班后最少休息 | 12 小时 | 夜班后最小休息时间 |
| 每天最多上班数 | 1 | 每人每天最多排几个班 |
| 每周最多工作时长 | 48 小时 | 每周累计工时上限 |
| 节假日排班模式 | 正常轮转 | 节假日是否特殊处理 |
| 周末差异化 | 关闭 | 周末是否采用不同排班策略 |

### 5.2 自定义规则

1. 点击「新建自定义规则」
2. 选择规则类型，设置参数
3. 设置适用范围（全部/指定组织）
4. 拖拽调整优先级

---

## 6. 排班管理

### 6.1 自动排班

1. 进入「排班管理」→「排班日历」
2. 点击「自动排班」
3. 设置排班周期（开始/结束日期）
4. 选择班次模板
5. 选择排班范围和人员
6. 点击「一键生成」

### 6.2 手动排班

1. 在日历视图中点击日期格子
2. 从右侧抽屉中选择班次和人员
3. 系统实时校验约束规则
4. 冲突项红色高亮显示

### 6.3 发布排班

1. 完成排班编排后点击「校验」
2. 查看校验报告（通过/警告/失败）
3. 处理失败项
4. 点击「发布」→ 确认弹窗 → 确认发布

**注意：** 已发布排班锁定，修改需通过调班流程。

### 6.4 撤回排班

1. 点击「撤回排班」
2. 按日期范围选择要撤回的排班
3. 确认后恢复为草稿状态

## 7. 角色权限管理

> 仅 admin 角色可访问此页面。

### 7.1 查看权限规格

点击「权限规格表」可查看当前支持的模块和操作列表。

### 7.2 创建自定义角色

1. 点击「新建角色」
2. 填写角色名称
3. 勾选权限矩阵（模块 × 操作）
4. 保存

### 7.3 为用户分配角色

1. 搜索目标用户
2. 点击「分配角色」
3. 勾选要分配的角色
4. 保存

---

## 8. 系统配置

> 仅 admin 角色可访问此页面。

| 配置项 | 说明 | 默认值 |
|-------|------|--------|
| 系统名称 | 显示在顶栏和标题 | 排班管理系统 |
| 单位名称 | 显示在首页看板 | 应急涉安部门 |
| 调班审批开关 | 开启后调班需审批 | 开启 |
| 排班审批开关 | 开启后排班需审核 | 关闭 |
| 管理员接收全部通知 | 管理员是否接收所有消息 | 开启 |
| 自动排班开关 | 是否启用月末自动排班 | 关闭 |
| 自动排班触发时间 | 月末自动排班执行时间 | 23:00 |
| 自动排班跳过已有 | 已有排班的日期是否跳过 | 关闭 |
| 自动排班最后执行 | 记录上次执行日期（防重复） | 自动维护 |

---

## 9. 消息与公告

### 9.1 发布公告

1. 进入「消息中心」
2. 切换到「公告」Tab
3. 点击「发布公告」
4. 填写标题、内容、目标范围
5. 发布后相关人员收到系统消息

### 9.2 广播消息

管理员可向全组织或指定范围发送广播消息。
