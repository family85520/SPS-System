# 普通用户操作手册

**文档版本：** V1.0
**最后更新：** 2026-07-10
**适用对象：** 组长、普通队员

---

## 1. 登录系统

1. 打开浏览器访问系统地址
2. 输入用户名和密码
3. 首次登录需修改密码

**我的账号：** 用户名 = 工号

---

## 2. 工作台

登录后默认进入工作台页面，展示以下信息：

| 卡片 | 说明 |
|------|------|
| 排班概览 | 本期排班状态（草稿/已发布）、约束冲突数量 |
| 今日值班 | 今天各班次值班人员和领导 |
| 快捷操作 | 自动排班、排班日历、调班申请、消息中心 |
| 待处理事项 | 待审批调班、待确认换班、未读消息 |
| 最近公告 | 最新 5 条公告 |

---

## 3. 查看排班

### 3.1 日历视图

1. 进入「排班管理」
2. 使用顶部导航切换月份
3. 每个日期格子显示当天班次：
   - 色块颜色 = 班次颜色
   - 上方小标签 = 值班领导
   - 红色边框 = 存在冲突

### 3.2 查看详情

点击班次色块，右侧弹出详情面板：
- 班次名称和时间
- 值班领导和人员列表
- 冲突提示（如有）

### 3.3 个人排班统计

在人员列表中点击某人的姓名，可查看其近 30 天的排班统计：
- 总排班天数
- 累计工时
- 夜班次数

---

## 4. 调班申请

### 4.1 指定换班

适用于你和特定同事协商好换班：

1. 进入「调班管理」
2. 点击「发起换班申请」
3. 选择调班类型：**指定换班**
4. 选择我的班次和目标同事的班次
5. 填写申请原因
6. 提交后系统通知对方确认

**流程：**
```
提交 → 对方确认 → 审批（如开启） → 完成
```

### 4.2 开放替班

适用于找人替你值班：

1. 进入「调班管理」
2. 点击「发起替班申请」
3. 选择调班类型：**开放换班**
4. 选择我的班次
5. 填写原因
6. 提交后全组可见， anyone 可认领

**流程：**
```
提交 → 他人认领 → 审批（如开启） → 完成
```

### 4.3 撤回申请

- 在「我的申请」Tab 中找到对应记录
- 状态为"待确认"或"待审批"时可撤回

---

## 5. 消息中心

### 5.1 查看消息

1. 点击顶栏消息铃铛图标
2. 未读消息显示蓝色圆点
3. 点击消息打开详情

### 5.2 消息分类

| 分类 | 说明 |
|------|------|
| 排班通知 | 排班发布、撤回、修改通知 |
| 调班通知 | 换班申请、认领通知 |
| 审批提醒 | 调班审批结果 |
| 公告 | 管理员发布的公告 |

### 5.3 标记已读

- 单条：点击消息 → 标记已读
- 全部：点击「全部已读」

---

## 6. 个人信息

### 6.1 修改密码

1. 登录成功后点击顶栏用户名
2. 选择「修改密码」
3. 输入原密码和新密码

### 6.2 查看我的标签

在人员管理中可查看自己被分配的标签：
- "带班领导" — 自动排班时优先分配到领导组
- "新入职" — 配对管理中作为新员工标记

---

## 7. 常见问题

**Q: 为什么我看不到某些菜单？**
A: 菜单可见性由你的角色权限决定。如有疑问请联系管理员。

**Q: 已发布的排班可以修改吗？**
A: 已发布排班锁定，如需修改请通过调班流程。

**Q: 调班申请被拒绝了怎么办？**
A: 联系审批人查看拒绝原因，重新发起申请。

**Q: 如何知道自己的排班统计？**
A: 在排班管理页面可查看个人排班天数、工时、夜班次数统计。
