## 登录与账号

### Q1: 忘记密码怎么办？

**A:** 联系管理员重置密码：

1. 管理员进入「人员管理」页面
2. 找到该人员，点击「管理账号」
3. 选择「重置密码」，密码将重置为 `123456`
4. 用户登录后需立即修改密码

### Q2: 首次登录提示"必须修改密码"

**A:** 这是正常的安全机制。新创建的账号默认 `must_change_password=true`，首次登录会强制跳转到修改密码页面。

### Q3: 账号被禁用如何恢复？

**A:** 联系管理员：

1. 进入「人员管理」→ 搜索该人员
2. 点击「管理账号」
3. 将账号状态改为"启用"

### Q4: 用户名是什么？

**A:** 用户名 = 工号。创建人员时若勾选"创建登录账号"，用户名自动使用该人员的工号。

## 组织架构与人员

### Q5: 组织层级最多支持几级？

**A:** 最多 4 级。超过 4 级时创建会返回错误："组织层级最多支持 4 级"。

### Q6: 为什么不能删除某个组织？

**A:** 以下情况无法删除：
- 组织下有子组织
- 组织下有人员
- 组织下有排班记录

**解决方案：** 先移走人员和排班记录，再删除子组织，最后删除该组织。

### Q7: 人员标签和系统角色有什么区别？

**A:** 
- **人员标签**：用于排班引擎的身份标记（如"带班领导"、"新员工"），影响自动排班分配
- **系统角色**：控制功能权限（如 admin、scheduler），决定用户可以访问哪些菜单和 API

两者通过 `sys_role` 表的 `role_type` 字段区分：`tag` 表示标识，`role` 表示权限角色。

### Q8: 批量创建账号时提示"用户名已存在"

**A:** 说明该工号已作为用户名注册过其他账号。请检查：
1. 该人员是否已有登录账号
2. 是否有其他人员使用了相同工号

## 班次模板

### Q9: 跨天班次（如 22:00-06:00）时长如何计算？

**A:** 系统自动计算：结束时间 < 开始时间时，时长 = 结束 - 开始 + 24 小时。
例如 22:00-06:00 = 8 小时。

### Q10: 停用班次模板后已排班的记录会怎样？

**A:** 已发布的排班记录不受影响。停用的模板仅不参与新的自动排班。

### Q11: 如何复制班次模板？

**A:** 在班次模板详情页点击「复制」按钮，新模板名称自动添加"(副本)"后缀。

## 排班管理

### Q12: 自动排班生成后是草稿还是已发布？

**A:** 自动排班生成的记录默认为**草稿**状态（status=0），需要手动发布后才生效。

### Q13: 已发布的排班可以修改吗？

**A:** 已发布排班锁定，不可直接修改。如需调整：
1. 撤回排班（变为草稿）→ 修改 → 重新发布
2. 或通过调班流程修改个别人员

### Q14: 约束校验报告中的"警告"和"失败"有什么区别？

**A:**
- **警告**：建议调整但不阻塞发布（如"连续工作接近上限"）
- **失败**：违反硬性约束，必须修正后才能发布

### Q15: 为什么有些人没有被分配到排班？

**A:** 可能原因：
1. 人员状态不是"在岗"（status != 1）
2. 特殊规则排除了该人员（如 exclude_date、exclude_shift）
3. 约束规则过滤（如 MAX_CONTINUOUS_DAYS 已达上限）
4. 可用人员不足

**排查方法：** 查看排班生成的诊断消息（diagnostics 字段）。

### Q16: 跨月排班的人员配对会丢失吗？

**A:** 不会。配对关系持久化在 `sch_pairing` 表中，每月切换时自动加载上月配对并执行 1:1 替换（离职/入职人员）。

## 调班管理

### Q17: 调班审批开关关闭后流程是怎样的？

**A:** 
- 指定换班：对方确认后直接完成，跳过审批
- 开放换班：认领后直接完成

### Q18: 调班申请被拒绝后可以重新申请吗？

**A:** 可以。被拒绝的申请状态为 `rejected`，不影响发起新的调班申请。

## 消息与公告

### Q19: 收不到实时消息通知？

**A:** 检查以下几点：
1. 浏览器是否允许 WebSocket 连接（检查控制台有无 ws:// 错误）
2. Nginx 是否正确配置 WebSocket 升级（`Upgrade` 和 `Connection` 头）
3. 消息是否被永久隐藏（deleted_at 不为 NULL）

### Q20: 公告发布后如何撤回？

**A:** 管理员进入「消息中心」→「公告」Tab，找到对应公告点击「撤回」。撤回后可选择永久隐藏或删除。

## 系统配置

### Q21: 如何开启/关闭月末自动排班？

**A:** 管理员进入「系统配置」页面：
1. 找到「自动排班开关」，切换为开启
2. 设置触发时间（默认 23:00）
3. 选择涉及的组织和班次模板
4. 保存后，APScheduler 每 5 分钟检查一次，月末最后一天在配置时间 ±30 分钟窗口内自动执行

**防重复机制：** 系统通过 `auto_schedule_last_run` 配置项记录上次执行日期，同一天不会重复执行。

**触发条件（需同时满足）：**
1. 今天是当月最后一天
2. 当前时间在配置时间的 ±30 分钟窗口内
3. 今天尚未执行过自动排班

### Q22: 如何修改系统名称和单位名？

**A:** 管理员进入「系统配置」页面，修改「系统名称」和「单位名称」后保存。

## 部署与运维

### Q23: 如何备份数据库？

**A:** 
```bash
# 方式一：使用 pg_dump
pg_dump -U scp scp_db > backup_$(date +%Y%m%d).sql

# 方式二：使用 Docker
docker exec sps-postgres pg_dump -U scp scp_db > backup.sql
```

### Q24: 如何查看后端日志？

**A:**
```bash
# systemd 方式
sudo journalctl -u sps-backend -f

# Docker 方式
docker logs -f sps-backend
```

### Q25: 修改配置后如何生效？

**A:**
```bash
# systemd 方式
sudo systemctl restart sps-backend

# Docker 方式
docker compose restart backend
```

## 技术问题

### Q26: 排班日历视图加载很慢？

**A:** 可能原因：
1. 日期范围过大（建议单次查询不超过 3 个月）
2. 数据库缺少索引（确认 `sch_schedule.date` 和 `sch_schedule.org_id` 有索引）
3. 网络延迟（检查 API 响应时间）

### Q27: 导出 Excel 文件打开乱码？

**A:** 确保使用支持 UTF-8 的 Excel 版本（Office 2013+）。旧版 Excel 可能需要手动指定编码。

### Q28: 如何升级系统版本？

**A:**
```bash
# 1. 备份数据库
pg_dump -U scp scp_db > backup_before_upgrade.sql

# 2. 拉取最新代码
git pull origin main

# 3. 安装新依赖
pip install -r requirements.txt
npm install

# 4. 执行数据库迁移
alembic upgrade head

# 5. 重启服务
sudo systemctl restart sps-backend
cd ../frontend && npm run build
```
